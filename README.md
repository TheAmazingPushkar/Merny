# Dhrustikona: AI-Powered News Aggregator

Modern news consumption is broken. Readers are trapped in algorithm-driven echo chambers, seeing only one heavily biased angle of a story. 

**Dhrustikona** does the heavy lifting of media literacy. It gathers articles from various publishers, clusters them by event, and uses Large Language Models to extract shared facts and highlight how different sources spin the same narrative.
